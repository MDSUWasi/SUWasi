Privacy Policy

A clear explanation of how this portfolio is hosted, the limited analytics it uses, and what to expect when following external links. Last updated: 23 November 2026.

Overview

This is a personal, non-commercial portfolio website. It does not require an account, does not sell anything, and does not intentionally ask visitors to submit personal information. The site owner does not use any analytics for advertising and does not sell or share visitor analytics data.

Hosting: GitHub Pages and Cloudflare

This website is served through GitHub Pages, GitHub's free static hosting service. As with any web host, GitHub automatically logs technical request data from visitors, such as the referring site, date and time of the visit, pages viewed, and links clicked, as described in GitHub's own General Privacy Statement. This log data is managed by GitHub and is not accessible to the site owner.

Requests are also processed by Cloudflare, which provides security, performance, and DNS services for this domain on its free plan. Cloudflare processes End User interactions with Internet properties that use its services; the information processed may include IP addresses, traffic routing data, and system configuration information, as described in Cloudflare's Privacy Policy. Cloudflare states that it does not sell the personal data it processes on behalf of its customers. Cloudflare's Web Analytics are privacy-first and do not use client-side state such as cookies or localStorage, and do not fingerprint individual users.

Website analytics

This website uses Cloudflare (Web Analytics), Umami Analytics, and Google Search Console to understand how the site is found and which pages are visited. This information helps improve the portfolio and its content.

  • Cloudflare Web Analytics measures visits at the network edge without tracking individual user behaviour across the web and without profiling users.
  • Umami is configured for privacy-focused, aggregated website measurement.
  • Google Search Console provides site-performance information (such as how often the site appears in search results) to the site owner only; it is not a visitor-facing feature.

Cookies and personal information

This site does not intentionally use cookies to identify visitors, and it does not ask visitors to submit personal information. The site's theme preference may be stored locally in your browser (local storage) so the display setting can be remembered.

Analytics services and the hosting providers described above may process technical request information as needed to provide their services. Please consult their current privacy documentation for details about their processing and retention practices.

External websites

Pages on this site may link to third-party websites and services (for example, GitHub repositories, LinkedIn, or Bluesky). Once you follow an external link, that site's own privacy policy, terms, and analytics practices apply. This policy does not cover those external services.

Changes and contact

This policy may be updated when the site, its hosting, or its analytics practices change. For questions about this policy, contact shafiun.wasi@outlook.com. See also the Terms and Conditions.
